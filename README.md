# 🧬 DNA Sequence Analyzer

## Description

This is my first biotechnology-related Python project.

The program accepts a DNA sequence from the user and performs basic sequence analysis.

## Features

- ✅ Counts A, T, C and G
- ✅ Calculates DNA sequence length
- ✅ Calculates GC Content
- ✅ Calculates AT Content
- ✅ Validates DNA input

## Technologies Used

- Python 3

## Example

Input

```
ATCGATCG
```

Output

```
Length: 8

A: 2
T: 2
C: 2
G: 2

GC Content: 50.00%
AT Content: 50.00%
```
